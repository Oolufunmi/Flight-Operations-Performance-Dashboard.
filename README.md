# Flight-Operations-Performance-Dashboard.
### Power BI dashboard analyzing flight operations, delays, cancellations, and airport traffic to uncover operational performance insights.# Flight Operations Performance Dashboard

## 📊 Project Overview
Flight delays and cancellations are common challenges in airline operations. Without proper visibility into operational data, it becomes difficult to identify the factors driving these disruptions.

This project analyzes flight operational data to uncover patterns in flight performance, delay causes, and airport activity. The goal is to transform raw data into actionable insights that help monitor operational efficiency and support data-driven decision-making.

---

## 🎯 Business Problem
Airline operations generate large volumes of data across multiple airports and carriers. Decision-makers often need quick answers to questions such as:

- Which airports experience the highest flight traffic?
- What are the main causes of flight delays?
- Which airlines demonstrate stronger operational performance?
- How do delays and cancellations affect overall operations?

This dashboard provides a centralized view of key operational metrics to help identify inefficiencies and monitor performance.

---

## 📁 Dataset
The dataset contains flight operational records including:

- Flight activity across airports
- Airline carrier information
- Delay causes
- Cancellation records
- Operational performance metrics

The dataset used in this project contains **over 2 million flight records**.

---

## 🛠 Tools & Technologies
- **Power BI** – Dashboard development and visualization  
- **DAX** – Calculated measures and performance metrics  
- **Data Modeling** – Data relationships and transformation  

---

## 📈 Dashboard Features
The dashboard provides insights into:

- Total flight activity across major airports
- Airline performance comparison
- Flight delay and cancellation metrics
- Breakdown of delay causes (weather, carrier issues, system delays, etc.)
- Airport traffic distribution

Key metrics tracked include:

- Total Flights
- Delayed Flights
- Cancelled Flights
- Flight Delay Causes
- Airport Traffic Volume

---

## 🔍 Key Insights
Some insights revealed from the analysis include:

- Certain airports handle significantly higher flight volumes compared to others.
- Carrier-related issues and weather conditions contribute to a large portion of delays.
- Airline performance varies across operational environments and airport traffic levels.
